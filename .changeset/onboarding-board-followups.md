The plan review's "Sign in" link now brings you back to the project you were building instead of the dashboard. Tutorial arrow keys no longer also step the tour while you use a slider, radio button, tab list or similar control, and pressing Escape to close the Export dialog during the tour closes only the dialog. While you play, the arrow keys steer the game instead of stepping the tour. The MCP bridge token (`?mcp=`) is no longer copied into sign-in links, so sign in before opening the editor with `?mcp=<token>`, or reopen that URL once you are signed in.
