Some 2D games published before scenes recorded whether they are 2D or 3D now play in 2D on their `/play` page, without the creator republishing (#10368). This covers games built from sprites, tilemaps, 2D skeletons or 2D physics. It does not cover games the AI pipeline generated in a 2D project, which are built from plain planes with 3D physics: nothing in such a scene tells it apart from a 3D game, so it still plays in 3D until it is republished. Those games state no type, so the player loaded them in the default 3D mode, where no 2D camera exists, and they showed a blank canvas. The player now looks at what such a game contains. If every entity is clearly 2D content (a sprite, a tilemap, a 2D skeleton or enabled 2D physics), with lights allowed alongside and nothing 3D-only (terrain, CSG, a glTF model, an imported asset), it switches to 2D before play, the same way it already does for games that state 2D. Anything mixed or unclear plays in 3D, as before. This applies to `/play` only and is recorded as a Sentry breadcrumb each time it happens. The editor and saved scenes still never guess the type, and republishing a game writes the type into it.
