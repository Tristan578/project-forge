Credit the original creator on remixed games (#7858).

Forking a published game already recorded where it came from, but nothing read that record back, so a remix looked like an original and the source creator got no credit. The community game detail now reports how many times a game has been forked and, for a game that is itself a fork, which game and creator it came from, with a link to that game's play page. If the original has since been unpublished or removed, the detail says only that the source is no longer available and exposes none of its details. Adds an index on the fork table's forked-project column for the lookup.
