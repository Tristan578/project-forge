The sign-in, sign-up and documentation pages now name themselves as canonical, the same way every other page in the sitemap already does. Before, those three were the only sitemap pages with no canonical, and because production answers on both spawnforge.ai and www.spawnforge.ai, Google Search Console reported them as "Duplicate without user-selected canonical". The canonical is a path resolved against the site URL, so it follows whichever host the site is configured to treat as primary.
