Fix terrain ground being silently dropped in `create_level_layout`. The terrain branch read the stale `primaryId` (only set by the async SELECTION_CHANGED event, so null on a fresh scene) to parent the terrain ground, so the ground was never reparented and was reported as missing. `spawnTerrain` now generates the entity id client-side and returns it synchronously, mirroring the `spawnEntity` primitive path; the compound handler parents the terrain ground to that returned id. (#8749)
