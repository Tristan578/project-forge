# Skill-lint ratchet baseline — skill directories allowed to carry KNOWN debt.
#
# check-skills.sh enforces the best-practice rules on every skill. A finding in a
# skill listed here is downgraded to a warning (known debt); a finding in any
# skill NOT listed here fails the gate. This is the same ratchet the repo uses for
# openapi-route-sync, and matches the #8676 stance: enforce clean on new/touched
# skills, track the legacy tail rather than block on it.
#
# Rules:
#  - One skill directory name per line (the dir under .claude/skills/).
#  - When you fix a skill, REMOVE its line — the linter warns if a baselined skill
#    now lints clean, so this list cannot silently rot.
#  - Do NOT add a new skill here to dodge the rules. New skills must lint clean.
